This is a console-based Tic-Tac-Toe game with an AI opponent using the Alpha-Beta pruning algorithm.
The AI can play as X or O, and it chooses optimal moves to either win or draw.
The human player inputs moves by selecting a cell number (1-9).
The game prints the board after every move and announces the winner or a draw.
Alpha-Beta pruning ensures faster AI decision-making compared to a normal minimax algorithm.
