1-->This is a Tic-Tac-Toe game featuring an AI opponent that uses the Minimax algorithm with Alpha-Beta Pruning for optimal decision-making. The AI can play as either X or O and always chooses the best possible move to win or draw the game. Players make moves by entering cell numbers (1–9), and the board updates after each turn. Alpha-Beta pruning improves the AI’s efficiency by cutting off unnecessary branches, making it faster than standard Minimax. The time complexity is O(b^d) for normal Minimax and reduces to O(b^(d/2)) with Alpha-Beta pruning, where b is the branching factor and d is the depth.
2-->This is a ChessGame built using the Minimax algorithm with Alpha-Beta Pruning. It allows a human player to play against the computer by entering moves in UCI format (e.g., e2e4). The AI evaluates board positions using a simple piece-value heuristic and selects optimal moves up to a given search depth. Alpha-Beta pruning improves efficiency by reducing unnecessary move evaluations compared to normal Minimax. The program supports both White and Black play and displays the updated board after every move. The time complexity of Minimax is O(b^d), which reduces to O(b^(d/2)) with Alpha-Beta pruning, where b is the branching factor (possible moves) and d is the search depth.
